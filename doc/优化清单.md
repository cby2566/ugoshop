## 一、技术债（第一批：小改动高收益）

### T1 Element Plus 移除 ✅（0509539）

**问题**：`app/src/main.ts` 全量引入 Element Plus 组件库 + 全量样式
（`import ElementPlus from 'element-plus'` + `dist/index.css`），但全站实际只
使用了一个 API——`ElMessage`（21 处调用，用于操作反馈提示）。

**代价**：最近一次生产构建 `dist/assets/index-*.js` 为 **1,097.97 kB**
（gzip 362.81 kB）、`index-*.css` 396.14 kB，Element Plus 占大头，构建时持续
报 chunk 超 500 kB 警告。全量 CSS 中 99% 规则（按钮/表单/表格/弹窗……）从未命中。

**修复方案（推荐：彻底移除）**：
1. 新建 `app/src/utils/toast.ts`：手写轻量 toast（约 40 行——固定定位容器 +
   站内主色提示条 + 自动消失动画），导出 `toast(msg, type)`，风格与现站一致
   （参考原站红黑灰配色，错误用 #f70800 系）；
2. 全局替换 21 处 `ElMessage.error/success(...)` → `toast(...)`；
3. `main.ts` 删除 Element Plus 引入（组件库、locale、全量 CSS 三行）；
4. `package.json` 移除 `element-plus`、`@element-plus/icons-vue` 依赖。

**备选（收益打折）**：按需引入（`unplugin-auto-import` + `unplugin-vue-components`），
仅保留 ElMessage；bundle 仍会保留 EP 的消息组件样式链。

**预期收益**：bundle 约 1.1MB → ~250KB 级；node_modules 体积大幅下降；构建警告消失。

**验证要点**：
- `npm run build -w app` 后 dist 体积对比（应低于 300KB JS）；
- 逐页触发提示场景（列表页价格排序失败/购物车操作/注册校验/登录失败等）
  确认 toast 样式与出现/消失动画正常；
- 确认 `node_modules` 无 element-plus 残留、`vue-tsc` 通过。

### T2 路由懒加载 ✅（0509539）

**问题**：`app/src/router/index.ts` 六页视图全部静态 import，打进单一 chunk，
首屏加载全站代码。

**修复方案**：路由组件改 `() => import('@/views/XxxView.vue')` 动态引入，
让 Vite 自动按页分包（配合 T1 后首页只载入首页代码）。

**验证要点**：构建产物出现 `HomeView-*.js`、`CartView-*.js` 等多 chunk；
逐页切换正常、无白屏；`vue-tsc` 通过。

### T3 页面专属 CSS 未分包 ✅（0509539）

**问题**：`app/src/main.ts` 全量引入 9 个全局 CSS，其中 `foodlist_main.css`
（列表页）、`itemdetailed.css` + `magnifier.css`（详情页）、`car.css`（购物车页）、
`reg.css`（登录/注册页）为页专属样式，却全部打进主 CSS chunk（当前产物
387.7 KB），每页都加载全站样式。

**修复方案**：将上述页专属 CSS 的 import 从 `main.ts` 移到对应视图组件
（ListView → foodlist_main.css；ItemView → itemdetailed.css + magnifier.css；
CartView → car.css；LoginView/RegView → reg.css）。配合 T2 路由懒加载，Vite
自动把各页 CSS 拆到对应 chunk，仅载所需样式。`base.css` / `homepage.css` /
`homepage_main.css` 为壳层样式（TopBar/SiteHeader/CategoryNav/SideBar/SiteFooter
共用），保留在 main.ts。

**实施注意**：迁移前逐个核对各 CSS 选择器命中范围，确认无跨页复用再移，避免样式回归。

**预期收益**：主 CSS 明显下降，各页只加载自己样式（与 T1/T2 同属打包瘦身）。

**验证要点**：构建后 `dist/assets` 出现 `ListView-*.css` 等分 chunk；逐页切换
无样式回归、无布局抖动；`vue-tsc` 通过。

### T4 菜单接口重复请求（极小）✅（4487f0f）

**问题**：`CategoryNav.vue` 挂在 App 壳层，`onMounted` 调 `menu.fetchMenu()`。
普通页间切换组件不重建，但**从窄壳页（登录/注册/购物车）回到普通页时**重新
挂载，会重复 `GET /api/menu`。

**修复方案**：`stores/menu.ts` 加 `loaded` 标志，已加载则直接返回；或组件里
`onMounted(() => { if (!menu.items.length) menu.fetchMenu() })`。

**验证要点**：普通页与窄壳页来回切换，Network 面板 /api/menu 仅请求一次。

### T5 无 404 路由兜底（小）✅（4487f0f）

**问题**：`router/index.ts` 只有六页路由，无 catch-all；访问未知路径（如
`/nonsense`）渲染空白页。

**修复方案**：加 `{ path: '/:pathMatch(.*)*', redirect: '/' }` 兜底回首页
（或做一个轻量 404 页）。

**验证要点**：访问 /nonsense 回首页；六页路由不受影响；`vue-tsc` 通过。

## 二、点击副作用（第一批）

### C1 空 href 死链点击整页刷新（净约 28 处）✅（0509539）

**问题**：全站存在大量 `href=""` 的 `<a>`。浏览器语义中空 href = 跳转当前 URL，
点击导致**整页刷新**（丢失 SPA 状态、体验割裂）。静态模板实测分布（grep 基线）：

| 位置 | 数量 | 说明 |
|------|------|------|
| SiteFooter 页脚四栏 | 12 | 装饰链接（购物流程/支付宝/服务承诺等），原站无对应页面 |
| LoginView L48/52/73、RegView L142/150/179 | 6 | 横幅图、帮助中心、忘记密码、服务承诺 |
| HomeView L80/104 TV 直播区 | 2 | toTv 入口 + 直播卡链接 |
| ListView L101「评论 40」 | 每卡 1 处 | |
| ItemView「送至」地址链接 | 1 | 原站为收货地址选择占位 |
| CartView L209「立即结算」 | 1 | 已带 @click.prevent，随 I3 接线 |
| CategoryNav hover 菜单 kinds 项 | 动态 | `href=""` 分类项（模板 2 处 + 动态展开） |

> 说明：页脚底部信息条约 15 处为无 href 的 `<a target="_blank">`，点击无副作用，**无需处理**；
> 已带 @click.prevent 的（LoginView L83 免费注册 / RegView L144 现在登录 / CartView L209）不在此列。

**修复方案**：视觉原样保留，统一消除刷页副作用——
- 装饰/无功能链接：`href=""` → `href="javascript:void(0)"`；
- 或模板统一加 `@click.prevent`（对已有 @click 接线的无需处理）。

**验证要点**：抽样点击页脚/帮助中心/送至/评论数，确认 URL 不变、无刷新；
已接线链接（免费注册、xnav 首页/食品等）行为不回归。

### C2 顶部 5 个无对应功能死链（说明项，保持原样）

顶部「我的订单/我的关注/资讯/品牌馆/手机优品惠」为原站遗留占位，新站无对应
页面。当前为 `javascript:void(0)` 无副作用，**建议保持原样**；若后续做订单/
收藏功能再逐个接活（「我的订单」在做了下单流程后接 `/orders` 最自然）。

## 三、交互细节

### I1 列表页商品卡缺 cursor:pointer（极小）✅（0509539）

**问题**：`ListView.vue` 商品卡 `@click="goDetail(sid)"` 已接线跳详情，但 CSS
无 `cursor: pointer`，用户无法从光标得知可点。

**修复方案**：`foodlist_main.css` 或 ListView 增补样式中为 `.flist_t .goods`
加 `cursor: pointer;`（1 行）。

**验证要点**：列表页悬停商品卡光标变手型；点击跳详情不回归。

### I2 搜索框接真功能（中）✅（4487f0f）

**问题**：`SiteHeader.vue` 搜索框（`.schin`）与搜索按钮（空 `<a>`）完全无功能
——无 v-model、无事件。电商站最基本的功能闭环缺口。

**修复方案**：
1. server `routes/products.ts` 列表接口加 `q` 参数：`ilike(name, %q%) OR
   ilike(brand, %q%)`（Drizzle 参数化，天然防注入）；
2. SiteHeader 加 `v-model` + 回车/按钮点击 → `router.push({ path: '/list',
   query: { q } })`；
3. ListView/products store 读路由 `q` 参数透传给接口；有结果正常出卡、无结果
   给空态提示（「未找到相关商品」）；
4. 首页/列表/详情页的搜索框为共用组件，一处接线自动全站生效（登录/注册/购物车
   为窄壳页无搜索框）；
5. 列表页 `h1`「进口食品」为硬编码标题，同步改为跟随当前分类/搜索词显示
   （「全部商品」「搜索：xxx」等），与 D1 落地后联动。

**验证要点**：搜索「美的」出对应商品；搜索乱码出空态；URL 带 `?q=` 可刷新还原；
空关键词不触发跳转。

### I3 购物车「立即结算」死链（极小）✅（4487f0f）

**问题**：CartView「立即结算」为空 href，点击刷页；站点无下单流程。

**修复方案（最小）**：点击 toast「演示站点，暂未开通下单功能」+ `@click.prevent`。
真做订单确认页/订单表属于功能扩建（D 类工作量），不在本项。

**验证要点**：点击出提示、不刷新；购物车其余操作（数量/删除/全选）不回归。

### I5 主轮播增强（小）✅（4487f0f）

**问题**：首页主轮播（HomeView luntu1-5）只有自动淡入切换，无指示圆点、
无悬停暂停。原站 myfocus 焦点图组件（被注释未启用）本身带按钮/序号。

**修复方案**：增补 `ul.ugoshop-carousel` 底部指示圆点（绝对定位，5 个小点，
当前高亮站内主色）；`mouseenter` 暂停定时器、`mouseleave` 恢复；点击圆点
跳对应帧。样式参考原站 myfocus mF 风格（半透明灰底白点）。

**验证要点**：圆点数量/高亮与当前帧同步；悬停暂停、移开恢复；点击圆点立即
切帧；`prefers-reduced-motion` 下自动轮播建议同时停用。

### I4 侧边栏二维码格（小）✅（4487f0f）

**问题**：SideBar `data-ce="3"` 二维码格 hover 显示「二维码」标签，点击无行为
（原站同格有二维码弹出层逻辑，rebuild 未移植）。

**修复方案**：点击弹出二维码大图浮层（素材用原站 `css-img` 中的二维码图，
或 assets 内 AI 资产）；再次点击/Esc/点空白关闭。纯前端，无后端改动。

**验证要点**：弹层位置不遮挡侧栏「向上」格；关闭交互顺畅；cart/登录页
（窄壳页无侧栏）不受影响。

### I6 购物车行商品名/图无详情回跳（极小）✅（4487f0f）

**问题**：`CartView.vue` 商品行商品名与图的链接为 `href="javascript:;"`，点击无
任何行为；列表页与详情页均已接详情跳转，购物车缺最后一环。

**修复方案**：商品名与图接 `@click.prevent="router.push('/item/' + item.sid)"`。

**验证要点**：购物车点商品名/图跳对应详情；数量加减/删除/勾选不回归。

### I7 列表页无加载态/空态（极小，与 I2 合并实现）✅（4487f0f）

**问题**：`ListView.vue` 模板未使用 store 的 `loading`；接口返回 total=0 时页面
直接空白，无「未找到商品」提示。

**修复方案**：列表区加轻量加载态（灰底占位即可）；`store.items.length === 0` 时
显示空态文案（与 I2 搜索无结果共用「未找到相关商品」）。

**验证要点**：首次进入可见加载态；无结果分类/搜索出空态文案；分页不回归。

### I8 详情页锚点点击污染 URL hash（极小）✅（4487f0f）

**问题**：`ItemView.vue` 三个详情 tab 用 `href="#k1/k2/k3"`，点击改写 URL hash
（SPA 下产生无效历史记录，刷新不定位）。

**修复方案**：`@click.prevent` 阻止默认行为 + `scrollIntoView({ behavior: 'smooth' })`
手动定位；吸顶逻辑不变。

**验证要点**：点击 tab 正常滚动、URL 无 # 变化；吸顶不回归。

### I9 页面标题不随路由变化（小）✅（4487f0f）

**问题**：`index.html` 固定标题「优品惠 UGOShop」，列表/详情/购物车页不区分。

**修复方案**：`router.afterEach` 按路由设置 `document.title`：首页「优品惠
UGOShop」、列表「商品列表 - 优品惠」、详情「{商品名} - 优品惠」、购物车
「我的购物车 - 优品惠」、登录/注册「登录/注册 - 优品惠」。

**验证要点**：逐页切换浏览器标签标题正确；详情页含商品名。

## 四、数据维度工程（第三批：动 schema + seed + API）

### D1 列表页分类 tab 真过滤（中）✅（d5b2951）

**问题**：`ListView.vue` 顶部 7 个分类 icon（全部商品/进口食品/营养保健/休闲
食品/粮油干货/酒水茶饮/生鲜食品）为原站硬编码展示位，点击无任何效果。
根因：`products` 表无 `category` 字段（schema 仅有 sid/name/brand/price/
description/image/legacyUrl）。

**修复方案**：
1. `server/src/db/schema.ts` products 加 `category` text 字段；
2. `doc/products.json` 20 条商品补分类值（对齐 7 个 tab 的命名），seed 脚本同步；
3. `/api/products` 加 `category` 过滤参数；
4. ListView 分类 tab 加 active 态 + 点击刷新列表（「全部商品」不传过滤）。

**验证要点**：各 tab 出对应商品；「全部商品」恢复全量；分页与价格排序在
过滤态下仍正确；`db:push` + `seed` 幂等重灌不丢购物车（cart 表独立）。

### D2 销量/上架时间排序（中）✅（d5b2951）

**问题**：列表页「今日推荐/销量/上架时间/特惠」4 个查找项目前点击等效无操作
（注释明示「原站无对应数据维度」），仅价格两态排序为真。

**修复方案**：
1. schema 加 `sales`（integer，销量）与 `createdAt`（上架时间）字段，
   seed 里给 20 条商品合理散布值；
2. `/api/products` 的 sort 支持 `sales`/`created_at`；
3. ListView 查找项接真排序（销量/上架时间），「今日推荐/特惠」可保持摆设或
   定义为 sales 降序/价格升序的别名。

**验证要点**：各排序项结果顺序正确；与分类过滤（D1）叠加正常；价格两态排序
不回归。

### D3 详情页面包屑接真路由（小，依赖 D1）✅（d5b2951）

**问题**：`ItemView.vue` 面包屑「首页>美食>进口食品>冲调饮品>品牌」为静态文本，

## 六、部署与运维（部署前）

### P1 server 未托管静态产物（小）

**问题**：`server/src/index.ts` 只注册 API 路由；本地 dev 靠 Vite 5173 代理，
NAS 部署（vite 产物 + Fastify 同机）时 `app/dist` 无静态托管。

**方案**：server 引入 `@fastify/static` 托管 `app/dist`，并对非 `/api` 路径加 SPA
fallback（回 index.html）；或继续沿用「静态服务托管 dist + Fastify 反代 API」的
组合。

### P2 会话签名密钥默认值硬编码（极小）

**问题**：`server/src/index.ts` 的 `COOKIE_SECRET` 默认值 `ugoshop-rebuild-dev-secret`
写死在代码；本地练手可接受，部署到 NAS 若未覆盖则存在会话伪造风险。

**方案**：部署时通过环境变量注入随机密钥（`.env` 已在 .gitignore），文档补充启动说明。

### P3 数据库文件不入版本库（说明项）

**现状**：`server/data/ugoshop.db` 已被 .gitignore（git 仅跟踪 `.gitkeep`），符合
数据完整性惯例。NAS 部署时需整体迁移 `server/data/` 目录（用户/购物车数据
均在该文件），首次建库执行 `npm run db:push` + `npm run seed`。
