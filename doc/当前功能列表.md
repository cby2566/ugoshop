# UGOShop 当前功能详细清单

> 基于实际源码逐行分析，截至 2019 年最后一次编译状态。

---

## 全局功能（所有页面共享）

| 功能 | 状态 | 说明 |
|------|------|------|
| 公告滚动栏 | 代码写好但被注释掉 | `gongg()` 函数在 homepage 中被注释，公告区静态显示 |
| 登录状态检测 | 工作 | Cookie 检测用户名，有则显示"欢迎xxx"，无则显示"注册/登入" |
| 购物车数量 badge | 工作（需登录） | AJAX 查询 `car.php?flag=y`，更新顶部和侧边栏的数字 |
| 退出登录 | 工作 | 删除 Cookie，刷新页面 |
| 侧边栏（用户中心/购物车/二维码/向上） | 部分工作 | 鼠标悬停显示标签，点击购物车可跳转，点击向上回顶部 |
| 搜索框 | 无 JS 逻辑 | UI 存在但点击搜索无任何响应 |
| 导航栏分类 | 全死链接 | 首页/视频/食品/家居/美妆/服饰/音乐之声 全是 `javascript:void(0)` |
| 顶部链接 | 大部分死链 | 注册/登录可用，其余（我的订单、我的关注、资讯、品牌馆）全是空链接 |

## 一、首页 (homepage.html + home.js)

### 正常工作的功能

| 功能 | 说明 |
|------|------|
| 轮播图 | `sliderImg()` 自定义轮播插件：自动2秒轮播、悬停暂停、上下按钮、焦点指示器、方向感知动画 |
| 登录状态 | 检测 Cookie，显示欢迎语或注册/登录链接 |
| 侧边栏交互 | 悬停显示功能标签，点击购物车跳转购物车页，点击向上回到顶部 |
| 购物车数量同步 | AJAX 查询并更新 `.mycart span` 和 `.go_wu_che` |
| 缓动动画引擎 | `startMove()` 自定义动画框架，支持多属性、多对象、链式调用 |
| 表单验证工具 | `checkReg` 对象：手机号、邮箱、身份证、密码、URL、用户名、中文、日期等正则 |
| Cookie 工具 | 设置/读取/删除 Cookie |
| 敏感词过滤 | `filterTex()` 替换敏感词为 `**` |
| Vue 2 数据绑定 | 页面底部有 Vue 测试代码，显示"我是数据"/"我是数据10"（测试性质） |

### 有代码但被注释/未启用的功能

| 功能 | 说明 |
|------|------|
| 公告滚动动画 | `gongg()` 函数写好但 jQuery ready 中被注释 |
| 限时购左右切换 | `fnuxn()` 函数写好但被注释，左右箭头点击无效果 |
| 倒计时 | `setTime()` 工具函数存在，但页面上的倒计时是静态数字，无动态更新 |

### 纯展示/死链接

| 功能 | 说明 |
|------|------|
| TV直播区 | 3个相同的商品卡片，纯静态 HTML，无动态数据 |
| 品类精选/全球尖货 | 有标题区域，下方无实际内容 |
| 商品列表（首页底部4个商品） | 静态展示，不可点击 |
| 限时购倒计时 | 显示 `18:23:01` 静态数字，不是真实倒计时 |

## 二、食品分类列表页 (foodList.html + footList.js)

### 正常工作的功能

| 功能 | 说明 |
|------|------|
| 价格排序（升序） | 点击"价格"按价格从小到大排序（但排序后有 bug，立即被原始数据覆盖） |
| 登录状态检测 | 同首页 |
| 侧边栏交互 | 同首页 |

### 有代码但被注释/未启用的功能

| 功能 | 说明 |
|------|------|
| 初始数据加载 | `ahj()` 函数定义完整但调用被注释，页面加载时商品列表为空 |
| 分页功能 | `ahj2()` 函数定义完整但调用被注释，分页组件（页码+下一页按钮）存在但从未激活 |
| 销量/上架时间/特惠/今日推荐排序 | 点击无效果（只有价格排序绑定了事件） |

### 已知 bug

| bug | 说明 |
|------|------|
| 页面加载空白 | `ahj()` 和 `ahj2()` 都被注释，商品列表和分页从未初始化 |
| 排序失效 | 排序结果立即被 else 分支的原始数据覆盖 |
| 降序死代码 | 降序分支永远到不了 |
| 分页页码错误 | `(3-i)` 生成"3,2,1,0,-1,-2..."而非"1,2,3..." |
| 点击事件重复绑定 | `xun()` 内用 `.bind('click')`，每次重新渲染都叠加新 handler |
| `eval()` 用于排序 | `footList.js:84` 用 `eval()` 拼接字符串比较价格 |

## 三、商品详情页 (itemDetailed.html + item.js)

### 正常工作的功能

| 功能 | 说明 |
|------|------|
| 图片放大镜 | `MagnifierF` 插件：鼠标悬停放大、缩略图切换、左右箭头导航 |
| 数量选择器 | +/- 按钮调整购买数量（最小为1，无上限） |
| Tab 切换 | 商品详情/评论/服务说明 标签切换（`.asd` 样式类） |
| Tab 吸顶 | 滚动到 tab 区域时添加固定定位样式 |
| 加入购物车飞入动画 | `jquery-addShopping.js` 插件：商品图飞向购物车图标 |
| 加入购物车 AJAX | 先检查 `addCar.php` 是否已存在，再调用 `car.php` 增加/更新 |
| 登录状态检测 | 同首页 |
| 侧边栏交互 | 同首页 |

### 已知 bug

| bug | 说明 |
|------|------|
| 商品 ID 截取错误 | `location.search.substring(4)` 会截掉 `id=` 的前两个字符，传入错误的值 |
| `getfid()` 硬编码 `'123'` | 始终查询用户 `123` 的 fid，而非当前登录用户 |
| 飞入动画后 badge 不更新 | `endFunction` 中 `$("#num")` 元素不存在于 HTML |
| 商品描述字段被丢弃 | API 返回的 `SCON` 被获取但 `.goods_xiang` 元素不存在 |
| 相关推荐（大家都在看） | 两个空容器，从未被 JS 填充 |
| Cookie 过期时间 | `new Date()` 无偏移，部分浏览器视为已过期 |

## 四、购物车页 (CarCar.html + car.js)

### 正常工作的功能

| 功能 | 说明 |
|------|------|
| 购物车列表渲染 | AJAX 获取数据后动态渲染商品行 |
| 数量 +/- 调整 | 减到1停止，AJAX 同步到后端 |

| 登录状态检测 | 同首页 |

### 已知 bug

| bug | 说明 |
|------|------|
| 满168包邮提示 | 实际硬编码减10元（`ns-10`），与"满168包邮"文案不符 |

## 汇总：能用的 vs 不能用的

### 用户可以看到并交互的（前端能跑的部分）

- 页面完整渲染（轮播图、商品展示、导航、侧边栏、页脚）
- 轮播图自动播放 + 手动切换
- 图片放大镜效果
- 数量选择器（+/-）
- 价格排序（升序，但有 bug）
- 侧边栏悬停/点击（购物车跳转、回顶部）
- Tab 切换 + 吸顶
- 飞入购物车动画
- 实时验证码
- 实时表单验证（手机号、密码长度、密码确认）
- 登录/注册流程（需后端配合）

### 完全无法使用的（依赖后端）

- 所有 AJAX 请求（18 处调用 PHP 接口，全部 404）
- 登录/注册（后端 PHP 已死）
- 购物车增删改（依赖 `car.php`）
- 商品数据加载（依赖 `ulist2.php`）
- 商品详情数据（依赖 `ulist2.php?flag=i`）
- 购物车数量同步（依赖 `car.php?flag=y`）

### 死代码/半成品

- 公告滚动（写好但注释）
- 限时购轮播（写好但注释）
- 分页（写好但注释，页码还有 bug）
- Vue 2 测试代码（页面底部，测试性质）
- 3 个商品详情图片（`dog.PNG` / `dog2.PNG` / `优购80_*.jpg`）—— 有图片文件但从未在详情页正确使用
